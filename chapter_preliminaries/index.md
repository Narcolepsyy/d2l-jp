# 深層学習（ディープラーニング）の前提知識：数学とプログラミング
:label:`chap_preliminaries`

**深層学習（ディープラーニング）を学ぶ前提として**、データを効率よく扱うためのプログラミングスキル、多次元配列（テンソル）の操作、さらにモデル学習に不可欠な線形代数、微積分、確率統計の基礎を本章で扱う。

ディープラーニングの学習を始めるには、いくつかの基本的なスキルが必要である。
(i) データを保存し操作する技術。
(ii) 多様な情報源からデータを読み込み、前処理するためのライブラリの利用法。
(iii) 高次元データを扱うための基礎的な線形代数。
(iv) 損失関数を最小化する際に、各パラメータをどの方向へ調整すべきか判断するための微積分。
(v) 導関数を自動的に計算する仕組み。これにより、微積分の細部を逐一手計算しなくてよい。
(vi) 不確実性のもとで推論するための基本言語である確率論の基礎。
(vii) 行き詰まったときに、公式ドキュメントから必要な情報を見つけ出す力。

要するに、本章では本書の
*大部分* の技術的内容を理解するために
必要な基礎を手短に導入する。
